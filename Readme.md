## 🧰 Prerequisites

Make sure you have the following installed:

* Python 3.8+
* Git
* Copier

Install Copier using pip:

```bash
pip install copier
```

Verify installation:

```bash
copier --version
```

## 🚀 Step-by-Step Workflow

This repository is designed to work **directly from a remote Git repository** using Copier. Below are the exact commands used, as referenced in this demo.

### ✅ Commands Used in This Repository

* Generate a project from a **remote Copier template**
* 
```bash
copier copy --vcs-ref master https://github.com/shreyaskn72/copier_update_function_demo.git ./hello_world
```

* Update the generated project when the template changes
```
cd hello_world
```

If you want to update as per the master branch use the following command
```
copier update
```

If you want to update as per branch use the following command
```
copier update --vcs-ref dev
```

If you want to update as per tag use the following command
```
copier update --vcs-ref v0.2.0
```

These commands demonstrate how to:


* Pin the template to a specific Git branch (`master`)

## 📄 Understanding `.copier-answers.yml`

This file is automatically generated when the project is created using `copier copy`.

Example for running from git:
```yaml
# This file is managed by Copier.
# Do not edit manually.
_commit: 0808b57
_src_path: https://github.com/shreyaskn72/copier_update_function_demo.git
author: shreyas_k_n
project_name: hello_shreyas
```

Example2:

```yaml
_template: ../my_copier_template
_commit: a1b2c3d4
project_name: demo_app
author: Shreyas
version: 0.1.0
```

### Why this file is important

* Tracks the template source
* Stores user-provided answers
* Enables `copier update`

⚠️ **Do not delete this file** if you want update functionality.

## ❗ Common Mistakes & Lessons Learned

| Mistake                         | Outcome                             |
| ------------------------------- | ----------------------------------- |
| Template not committed to Git   | `.copier-answers.yml` not generated |
| Using `copier recopy` initially | Update fails                        |
| Manually copying files          | No update tracking                  |

**Key takeaway:**

> Copier updates work only when the template is Git-tracked and the project is created using `copier copy`.

---

## 🧠 When to Use Each Copier Command

| Command         | Purpose                              |
| --------------- | ------------------------------------ |
| `copier copy`   | Create a new project                 |
| `copier update` | Apply template updates               |
| `copier recopy` | Re-generate everything (destructive) |
